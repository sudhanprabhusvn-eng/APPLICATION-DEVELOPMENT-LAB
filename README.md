## 🚀 Running Experiments Locally

### Exp-1, Exp-2, Exp-3
Static HTML/CSS/JS files — open directly in any browser:
- `Exp-1/index.html`
- `Exp-2/application development exp2.html`
- `Exp-3/application development exp 3.html`

### Exp-4: Node Static Server
```bash
cd Exp-4/node-static-server
npm install
node server.js
```

### Exp-5: React App
```bash
cd "Exp-5/application development exp 5/05"
npm install
npm run dev
```

### Exp-6: Full-Stack Notes App
```bash
cd "Exp-6/application development exp 6/notes-app"
npm install
npm run dev
```
