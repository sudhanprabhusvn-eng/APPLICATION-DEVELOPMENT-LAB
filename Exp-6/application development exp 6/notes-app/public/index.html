Backend REST API Architecture (Exp 6)

This application implements full CRUD operations interacting with MongoDB via Mongoose ODM:

GET /api/notes Retrieve all notes (supports ?q=term)
GET /api/notes/:id Retrieve a single note by MongoDB ObjectId
POST /api/notes Create a new note (JSON body with title, content, etc.)
PUT /api/notes/:id Update an existing note by ObjectId
DELETE /api/notes/:id Permanently remove a note from MongoDB
GET /api/health Check server and MongoDB connection state
